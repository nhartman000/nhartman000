# Nicholas C. Hartman

Founder and Lead Technical Architect at [American Milestone Incorporated](https://americanmilestone.com).

I design and test deterministic control structures around stochastic AI systems, with emphasis on ontology engineering, symbolic state representation, constrained execution, runtime validation, and auditable traces.

## Selected work

- [TEXporT](https://github.com/nhartman000/TEXporT) — chat capture, passage markers, notes, and handoff exports through the Linux app and [browser extension](https://github.com/nhartman000/Texport-browser-extension).
- [MG8 Engine](https://github.com/nhartman000/mg8-engine) - runnable Python reference implementation for loading MG8 resources and producing event-level QSON traces.
- [MGate Keeper](https://github.com/nhartman000/mgate-keeper) - reproducibility experiment that applies structured gate requirements and state context to model requests.
- [NYCH](https://github.com/nhartman000/nych) - inspectable Python substrate for symbolic glyphs, locality/address traces, lexicon lookup, and visualization.
- [TCTA](https://github.com/nhartman000/TCTA) - formal specification and evaluation framework for trajectory-constrained transforms.
- [MG8](https://github.com/nhartman000/mg8) - bounded execution-unit specification and cross-format authority map.

## Evidence standard

Repositories distinguish among formal specifications, reference implementations, and experiments. A documented architecture is not presented as empirical validation; measured results belong with reproducible methods, fixtures, and test output.
